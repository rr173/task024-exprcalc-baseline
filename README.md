# task024-exprcalc

表达式计算器服务，仅使用标准库实现：接收一个数学表达式字符串与一组变量绑定，计算并返回结果；求值过程中的数学错误以结构化错误与错误类别返回。所有判定无持久化、不依赖任何第三方库、数据库或外部服务。

## 本地运行

```bash
go run . server --addr :8080
go run . --smoke-test
```

主要接口（请求体均为单个 JSON 对象，未知字段与多段 JSON 会被拒绝）：

- `GET /healthz`：健康检查。
- `POST /eval`：提交 `{"expr":"<表达式>","variables":{"x":3,...}}`，成功返回 `{"ok":true,"result":<数值>}`；求值语义错误返回 `200 {"ok":false,"error":"...","kind":"..."}`；表达式语法错误返回 400；请求体非法返回 400。

支持的语法：

- 字面量：整数与小数（`123`、`12.5`、`1.5e3`、`2e-2`、`.5`、`1.`）。
- 运算符：`+ - * / % ^`、一元正负号、比较 `> >= < <= == !=`（结果 1/0）、逻辑 `&& ||`（1/0，短路）。
- 标识符：`[A-Za-z_][A-Za-z0-9_]*`，大小写敏感；紧跟 `(` 为函数调用，否则为变量引用。
- 内置函数：`max/min`（≥1 参）、`abs/floor/ceil/round/sqrt`（1 参）、`pow`（2 参）、`clamp`（3 参）、`if`（3 参，短路）。

边界约束要点：

- 除零、取模零、数值溢出：`a/0`、`a%0`、`0^负数` 报错（不返回 ±Inf/NaN）；`%` 截断取模，符号同被除数（`-5%3=-2`、`5%-3=2`）；`±Inf`（如 `1e308*1e308`、`2^1024`）报溢出。
- 幂运算边界：`0^0=1`；负底数非整数次方报定义域错；`^` 右结合（`2^3^2=512`）且一元负号低于幂（`-2^2=-4`）；`^` 与 `pow` 同义；`sqrt(负数)` 报定义域错。
- 函数元数与短路：元数严格校验；`if`/`&&`/`||` 短路，未选中分支不求值（`0 && (1/0)` 返回 0 不报错，`if(0,1/0,42)` 返回 42）。
- 命名空间：标识符大小写敏感；调用位置函数优先，非调用位置取变量；未定义变量、未知函数报错。

## Docker
